# Plugins

This is a directory that contains all of my Roblox Studio plugins/plugin forks.

| Plugin Name | Description | License |
| --- | --- | --- |
| **[Init Framework](init-framework)** | One Click Game Setup. | FSL-1.1-ALv2 |
| **[Packager](packager)** | Easily Package/Unpack systems into your experiences. | Fork of likeablesea7's Custom Explorer; upstream licence applies |
| **[Studio Wally](studio-wally)** | Search and download Wally packages, without ever leaving Roblox Studio. | Fork of fewkz's Studio Wally (MIT); upstream licence applies |
| **[Bounding Box](bounding-box)** | Make a part that matches a model's bounding box, in one click. | FSL-1.1-ALv2 |
| **[Viewmodel Editor](viewmodel-editor)** | Editor specifically for creating, adjusting, or animating first-person viewmodels. | FSL-1.1-ALv2 |
| **[Infinite Ocean](infinite-ocean)** | Infinite Gerstner-wave ocean with buoyancy, swimming, and weather. | Proprietary (paid) |
| **[Flashback](flashback)** | Record gameplay on the server and play it back anywhere. | Proprietary (paid) |
