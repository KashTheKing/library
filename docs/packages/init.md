**My trusted module loader. Being reworked; the current version ships as a building block.**

Init requires and initializes your modules in a safe, ordered way. It is what nearly all of my games boot with. The package version is undergoing a rework, so for now it is distributed as the [Init building block](../building-blocks/init.md) and installed with the [Init Framework plugin](../plugins/init-framework.md).

## Status

The package is being reworked and is not on Wally yet. Watch the [source folder](https://github.com/KashTheKing/library/tree/main/packages/src/Init) or the Discord for the release. Until then, install the [Init building block](../building-blocks/init.md) with Packager, or set up a whole place with the [Init Framework plugin](../plugins/init-framework.md).
