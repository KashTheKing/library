## Installing any plugin

1. Open the plugin's Creator Store page and press **Get**, then **Install** (or open Studio's **Plugins** tab, **Manage Plugins**, and find it there).
2. Enable it in **Manage Plugins** if Studio asks.
3. Its button appears in the **Plugins** toolbar. Widgets remember their position and docking per plugin.

Plugin bugs go to the [Discord](https://discord.gg/6HYgCk22eD) or a [GitHub issue](https://github.com/KashTheKing/library/issues); say which plugin and paste the Output window.
