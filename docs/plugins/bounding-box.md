**Make a part that matches a model's bounding box, in one click.**

I made this plugin because I keep needing hitboxes for models. It cuts the process to a single button press, and pairs well with the [Hitbox package](../packages/hitbox.md), which can convert such a part into a scanning hitbox with `Hitbox.fromPart`.

## How to use

1. Select a model.
2. Press the **Bounding Box** toolbar button. A new part sized and positioned to the model's bounding box appears, selected.

## Optional configuration

To change the default properties of new bounding boxes:

1. Select a bounding box (or any part) whose properties you like.
2. Press the **Match Properties** toolbar button.

From then on every new bounding box copies that part's properties (Anchored, CanCollide, CanTouch, Transparency, Color and so on).
