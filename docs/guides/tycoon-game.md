# Tycoon game, full guide

<span className="library-card-meta library-card-meta--deprecated">planned</span>

A full walkthrough of building a tycoon game from an empty baseplate using the library: tagged buttons and droppers bound with [Binder](../packages/binder.md), per-tycoon state replicated with [Authority](../packages/authority.md), purchases and collection over [Packet](../packages/packet.md), input validated with [t](../packages/t.md), and the UI wired up with [GuiHandler](../packages/gui-handler.md).

This guide is being written. It will be published in parts here, with a matching video series on [YouTube](https://youtube.com/@KashTheKingYT). Its source lives at [`guides/tycoon-game`](https://github.com/KashTheKing/library/tree/main/guides/tycoon-game) in the repository, so you can watch that folder or the [Discord](https://discord.gg/6HYgCk22eD) for updates.

In the meantime, the [Components with Binder](./components-with-binder.md) guide covers the pattern the tycoon is built on.
