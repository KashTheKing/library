## The docs site

The site is built with [Moonwave](https://eryn.io/moonwave/) from `moonwave.toml`, `docs/`, `pages/` and the
doc comments in `packages/src`, the same setup as the [Infinite Ocean docs](https://kashtheking.com/infinite-ocean/).

```bash
npm install
npm run docs:dev       # preview at http://localhost:3000/library/
npm run docs:build     # static site in build/docs
npm run publish:docs   # build and commit into KashTheKing.github.io/library
```
